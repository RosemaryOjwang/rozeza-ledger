# Decision Log

This document records major architectural, product, and technical decisions made during the development of Rozeza Ledger.

---

## Decision #001

**Date:** 3 August 2026

### Decision
Use Django REST Framework for the backend and React for the frontend.

### Reason
- Strong community support
- Scalable architecture
- Clear separation between backend APIs and frontend
- Easier future mobile app integration

**Decision by**
- Rosemary
- Zablon

---

## Decision #002

**Date:** 3 August 2026

### Decision
Use PostgreSQL as the primary database.

### Reason
- Reliable relational database
- Excellent Django support
- ACID compliance for financial transactions
- Suitable for production-scale applications

**Decision by**
- Rosemary

---

## Decision #003

**Date:** 3 August 2026

### Decision
Name the platform "Rozeza Ledger."

### Reason
The name combines the founders' names:

- Ro → Rosemary
- Ze → Zephaniah
